# EchoChain


## Circular Economy & Secondary Market Lifecycle Analytics

EchoChain is an end-to-end data analytics project designed to connect internal manufacturing data with secondary-market product listings to analyze product lifecycle, resale value, refurbishment potential, and circularity.

## Problem Statement

Manufacturers have detailed visibility into products until the point of sale, but post-sale product activity often becomes a data blind spot. EchoChain combines internal manufacturing, Bill of Materials (BOM), and warranty data with secondary-market listing data to provide insights into product reuse, resale value, and circular economy opportunities.

## Technology Stack

- Python
- Scrapy
- Databricks
- Delta Lake
- PySpark
- Power BI
- Git & GitHub

## Data Pipeline

Secondary Market Data → Scrapy → Delta Lake → PySpark → Fuzzy Matching → Circularity Metrics → Power BI

Internal Manufacturing Data → Delta Lake → PySpark → Circularity Metrics
